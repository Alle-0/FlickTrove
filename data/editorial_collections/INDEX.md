# FlickTrove Editorial Collections (Saghe Cronologiche)

Questo archivio locale contiene le definizioni complete, i metadati e le sequenze cronologiche diegetiche (in-universe) di tutte le **Editorial Collection** supportate da FlickTrove.

Questi file JSON vengono distribuiti sia in `data/editorial_collections/` (per documentazione, ispezione rapida e versionamento git) sia in `app/src/main/assets/editorial_collections/` (per il fallback offline immediato dell'app).
